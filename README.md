# کلاس نهم | پلتفرم آموزشی پایه نهم

وب‌سایت یکپارچهٔ آموزشی پایهٔ نهم شامل صفحهٔ اصلی (هاب) و ۶ ماژول درسی مستقل.

## ساختار فایل‌ها

| فایل | نقش |
|------|-----|
| `index.html` | صفحهٔ اصلی — مرکز دسترسی به همهٔ درس‌ها (کارت‌های ورود، داشبورد، پیشرفت) |
| `riazi9.html` | ماژول ریاضی نهم |
| `farsi9.html` | ماژول فارسی نهم |
| `arabic9.html` | ماژول عربی نهم |
| `science9.html` | ماژول علوم نهم |
| `social9.html` | ماژول مطالعات اجتماعی نهم |
| `english9.html` | ماژول زبان انگلیسی نهم |

همهٔ فایل‌ها کاملاً مستقل‌اند (CSS و JS داخل خود فایل است) و فقط از یک منبع خارجی اختیاری (فونت وزیرمتن از Google Fonts) استفاده می‌کنند؛ اگر فونت در دسترس نباشد، صفحه‌ها با فونت جایگزین (Tahoma) بلافاصله نمایش داده می‌شوند. هیچ وابستگی به سرور، API یا فایل محلی وجود ندارد.

## انتشار روی GitHub Pages

1. یک مخزن (Repository) جدید در GitHub بسازید (مثلاً `grade9`).
2. هر ۷ فایل HTML را **در ریشهٔ مخزن** (کنار هم، بدون پوشهٔ اضافی) آپلود کنید.
3. از منوی مخزن: **Settings → Pages** را باز کنید.
4. در بخش «Build and deployment»، گزینهٔ **Source** را روی `Deploy from a branch` بگذارید.
5. Branch را روی `main` و پوشه را روی `/ (root)` تنظیم کنید و Save بزنید.
6. پس از یک تا دو دقیقه، آدرس سایت به این شکل فعال می‌شود:
   `https://<نام‌کاربری>.github.io/grade9/`
7. برای به‌روزرسانی، فقط فایل‌ها را در مخزن جایگزین کنید.

نکته: همهٔ لینک‌ها نسبی‌اند؛ بنابراین سایت زیر هر مسیری (root یا زیرپوشهٔ project) بدون تغییر کار می‌کند.
